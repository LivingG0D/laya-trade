# Phase 2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Measure Laya queried in its training format; train and evaluate a gradient-boosting entry signal.

**Architecture:** Pure modules `src/barrier.py`, `src/features.py`, `src/gbm_signal.py`; experiment scripts `experiments/laya_probe.py`, `experiments/train_gbm.py` reuse the history loader and evaluator.

**Tech Stack:** Python 3.12, numpy, pandas, scikit-learn 1.9, joblib, pytest.

**Spec:** `docs/superpowers/specs/2026-09-26-phase2-gbm-design.md`

## Global Constraints

- Barrier: TP 1.2%, SL 0.6%, 24 bars of 5m, entry next open, same-bar conflict = loss.
- Features use closed candles only; HTF candle counts once closed at or before the 5m bar close.
- Threshold 0.45 fixed; costs 4 bps fee + 2 bps slippage per side.
- Holdout = last 60 days, evaluated once.
